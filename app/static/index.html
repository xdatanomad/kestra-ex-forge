What runs in Kestra

The same clicks, step by step: purple boxes start in the portal, teal in a Kestra App, grey are Kestra tasks. Numbers follow the order of the tasks in the flow.

A service desk request flow: route_request

You type a request in the Service Desk tab. Kestra reads it, plans the steps, runs the right workflows and updates the ticket as it goes.

Provision a server, then install software flows: provision_server, install_software

Both can be started from a portal button or from a Kestra App form. They run the same flow either way.
